# 👥 Workforce & Data Analytics Portfolio

Welcome to my data analytics repository, blending behavioral research with systems thinking to build clean relational databases, automated workflows, and structured reporting pipelines.

---

## 📋 Featured Projects

### 1. Workforce Analytics & Relational SQL Optimization Sandbox
* **The Goal & Solution:** Transitioned unstructured, flat-file employee records and simulated HR survey data into a clean, queryable relational tracking database using SQLite.
* **The Takeaway:** Engineered an optimized multi-table schema (`Employees`, `Departments`, `SurveyResponses`) and used advanced SQL queries (JOINs, CTEs) to practice auditing system errors and mapping workforce retention trends.

### 2. Global Air Quality Framework & Data Integrity
* **The Goal & Solution:** Programmatically queried large-scale open data using **Google BigQuery** and Python to filter anomalies and establish validation baselines.
* **The Takeaway:** Managed end-to-end data integrity while safeguarding cloud compute limits.

### 3. Google BigQuery Data Wrangling: Hacker News Analytics
* **The Goal & Solution:** Evaluated high-volume data streams, troubleshooting reserved SQL keywords and optimizing architecture.
* **The Takeaway:** Shifted from expensive grouping to conditional filtering to accelerate pipeline performance.

### 4. World Bank International Education Analytics
* **The Goal & Solution:** Queried and transformed global education metrics against national GDP using Cloud Database Management.
* **The Takeaway:** Delivered comparative benchmarks to support evidence-based policy making.
